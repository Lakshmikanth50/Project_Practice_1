# Diwali Sales SQL Analysis

This repository contains SQL queries used to analyze a Diwali sales dataset. These queries help derive insights such as total revenue, customer behavior, gender-based trends, and product/category performance.

## 📁 SQL Files Included
- `Total_Revenue.sql`: Total revenue across all sales
- `Top_5_customers_by_spending.sql`: Top 5 customers based on spending
- `Revenue_by_state.sql`: Revenue generated per state
- `Gender_wise_revenue.sql`: Revenue breakdown by gender
- `Revenue_by_product_category.sql`: Revenue by product category
- `Female_customers_aged_26_35.sql`: Data on female customers aged 26–35
