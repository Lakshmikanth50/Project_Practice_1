# Diwali Sales SQL Analysis

This repository contains SQL queries used to analyze a Diwali sales dataset. These queries help derive insights into customer behavior, revenue breakdowns, and purchasing patterns.

## 🧠 Queries Included

- **Total_Revenue.sql**  
  Calculates total revenue from all sales.

- **Top_5_customers_by_spending.sql**  
  Identifies the top 5 customers based on total spending.

- **Revenue_by_state.sql**  
  Displays total revenue generated from each state.

- **Gender_wise_revenue.sql**  
  Breaks down revenue by customer gender.

- **Revenue_by_product_category.sql**  
  Analyzes revenue by product category.

- **Female_customers_aged_26_35.sql**  
  Filters data to show female customers aged 26–35.
